MRH English Mock

A Comprehensive Online English Learning and Assessment Platform

MRH English Mock is an educational platform designed to develop students' English language proficiency through structured lessons, practice exercises, mock examinations and AI-assisted evaluation.

Main Learning Modules

1. English Grammar
2. English Vocabulary
3. Translation (Bengali to English and English to Bengali)
4. Writing Skills
5. Online Mock Tests
6. AI-Based Answer Evaluation
7. Student Dashboard
8. Performance Reports and Progress Tracking

Technology

- Frontend: HTML, CSS and JavaScript
- Backend: Python
- Database: To be configured
- AI Integration: OpenAI and Google Gemini
- Version Control: GitHub
